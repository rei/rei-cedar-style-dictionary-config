# 🌲 rei-cedar-style-dictionary-config

The Style Dictionary configuration that generates and governs Cedar Design System token distribution.

## Overview

This repository contains the Style Dictionary transformations, filters, and formats that power Cedar's token ecosystem. It serves as the foundation for generating stable, governed token packages and enabling local token extensions.
